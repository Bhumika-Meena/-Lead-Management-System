##  Overview

This Lead Management System is built to simulate real-world CRM architecture with:

- Secure authentication  
- Structured sales pipeline  
- Role-based access control  
- Relational database modeling  

The goal is not just functionality — but clean system design and scalability.

---

##  Core Features

###  Secure Authentication  
- JWT-based login with encrypted passwords using bcrypt.

###  Role-Based Access  
- Admins manage users and assign leads.  
- Sales agents interact only with their assigned data.

###  Structured Lead Pipeline  
- New → Contacted → Qualified → Converted / Disqualified  
- Clear stage transitions ensure workflow clarity.

###  Insightful Dashboard  
 A calm, organized interface to monitor:
-  Lead distribution  
- Status metrics  
- User performance  

###  Activity Tracking  
- Every call, email, meeting, or note is logged for traceability.
